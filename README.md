# صيدلية الحازم — نظام إدارة وتحليل البيانات

تطبيق ويب لإدارة صيدلية، مبني بـ React + TypeScript + Vite، يشمل:

- **لوحة التحكم**: مؤشرات أداء (المبيعات، الأرباح، متوسط الفاتورة)، رسم بياني لاتجاه المبيعات والأرباح، توزيع المبيعات حسب الفئة، الأصناف الأكثر مبيعًا، تنبيهات المخزون المنخفض وقرب انتهاء الصلاحية.
- **الأدوية والمخزون**: إضافة/تعديل/حذف الأدوية مع السعر والكمية وتاريخ الصلاحية والمورد، وبحث سريع.
- **المبيعات**: تسجيل فاتورة بيع جديدة (بعدة أصناف) مع خصم الكمية تلقائيًا من المخزون، وسجل بآخر الفواتير.

البيانات تُخزَّن في `localStorage` بالمتصفح (بدون حاجة لخادم)، وتبدأ ببيانات تجريبية واقعية عند أول تشغيل. يمكن إعادة تعيينها من زر "إعادة تعيين البيانات التجريبية" في الشريط الجانبي.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```
