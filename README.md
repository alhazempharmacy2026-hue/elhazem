# صيدلية الحازم — تحليل المبيعات وأداء الصيدلية

أداة ويب لتحليل ومقارنة بيانات المتابعة اليومية للصيدلية (المبيعات، الأرباح، أداء تسجيل العملاء)، مبنية بـ React + TypeScript + Vite.

- **لوحة التحكم**: مؤشرات أداء (المبيعات، الربح، نسبة التسجيل بكود، متوسط الفاتورة، نسبة الدليفري، المرتجعات)، رسم بياني لاتجاه المبيعات والأرباح، تسجيل الفواتير بالكود (أداء الصيادلة)، توزيع طرق الدفع، توزيع قيمة الفواتير، ملخص سريع للمشتريات والمخزون، وقسم **مقارنة الفترات** (آخر ٧ أيام مقابل الـ٧ اللي قبلها، الشهر الحالي مقابل اللي فات، أو فترة مخصصة) — بيقارن المبيعات والربح، تسجيل العملاء بالكود، والمشتريات من صيدليات أخرى.
- **البيانات اليومية**: استيراد ملف CSV مُصدَّر من شيت المتابعة اليومية على جوجل شيت (الأعمدة تتعرّف تلقائيًا بالاسم العربي بغض النظر عن ترتيبها)، أو إضافة/تعديل/حذف يوم يدويًا.
- **المخزون والأصناف**: استيراد ملف الأصناف من برنامج الصيدلية (اسم الصنف، الكمية الحالية، سعر الشراء والبيع، حد الطلب الأدنى، المورد)، مع تنبيه فوري للأصناف اللي نفدت أو منخفضة عشان تتلحق قبل ما تضطر تشتري من برا.
- **الموردين والديون**: تسجيل كل مورد وحركاته (شراء بالآجل / سداد)، مع رصيد جاري (مديونية) تلقائي لكل مورد وإجمالي المديونية ككل — مفيد وانت رأس مالك محدود وعليك التزامات.
- **الشراء الاضطراري من برا**: تسجيل كل مرة اضطريت تشتري صنف من صيدلية تانية بسبب نفاد المخزون (الصنف، من فين، الكمية، سعر الشراء الفعلي مقابل سعر الجمهور)، مع قائمة بالأصناف الأكتر تكرارًا عشان تعرف تزود حد الطلب الأدنى ليها وتوقف النزيف ده.

البيانات تُخزَّن في `localStorage` بالمتصفح (بدون خادم)، وتبدأ ببيانات تجريبية للمبيعات فقط عند أول تشغيل (المخزون والموردين يبدأوا فاضيين لحد ما تستورد بياناتك الحقيقية).

## استيراد البيانات من جوجل شيت

من الشيت: **ملف > تنزيل > قيمة مفصولة بفواصل (.csv)**، ثم من صفحة "البيانات اليومية" اضغط **استيراد CSV** واختر الملف. زر "تنزيل نموذج الأعمدة" بيدّيك ملف فيه كل أسماء الأعمدة المتعرّف عليها كمرجع.

## استيراد الأصناف من برنامج الصيدلية

صدّر من برنامج الصيدلية ملف Excel/CSV فيه الأعمدة: اسم الصنف، الكود، الوحدة، التصنيف، الكمية الحالية، حد الطلب الأدنى، سعر الشراء، سعر البيع، المورد. من صفحة "المخزون والأصناف" اضغط **تنزيل نموذج الأعمدة** لمرجع بالأسماء بالظبط، ثم **استيراد CSV**. لو عمود "المورد" موجود، الموردين الجداد بيتسجّلوا تلقائيًا في صفحة "الموردين والديون". أعد الاستيراد بشكل دوري لتحديث الكميات.

## التشغيل محليًا

```bash
npm install
npm run dev
```

## البناء للإنتاج

```bash
npm run build
```

النشر يتم تلقائيًا على GitHub Pages عبر GitHub Actions مع كل push.
