# موقع صيدلية الحازم — طلب أونلاين

موقع العملاء لتصفح الأدوية وطلبها أونلاين من صيدلية الحازم: تصفح وبحث، رفع روشتة للأصناف اللي محتاجاها، دفع عند الاستلام أو أونلاين عن طريق Paymob، وتتبع الطلب لحظة بلحظة.

يعتمد بالكامل على [Supabase](https://supabase.com) كـ backend (قاعدة بيانات + تسجيل دخول + تخزين صور + تحديثات حية) — مفيش سيرفر منفصل.

## التشغيل محليًا

1. من جذر الريبو: `npm install` (بيثبت كل تطبيقات الـ monorepo مرة واحدة).
2. انسخ `.env.example` هنا لـ `.env` وحط بيانات مشروع Supabase بتاعك (لسة معملتش مشروع؟ راجع `SETUP.md` في جذر الريبو).
3. `npm run dev` (من هنا أو `npm run dev:web` من الجذر).

## البناء للإنتاج

`npm run build` — لازم مشروع Supabase حقيقي مربوط عشان الموقع يشتغل فعليًا بعد النشر، لكن البناء نفسه بينجح حتى من غير مفاتيح حقيقية.

## ملاحظة عن الدفع

النسخة دي شغالة بالكامل بـ "الدفع عند الاستلام" من غير أي إعداد إضافي. الدفع الإلكتروني عن طريق Paymob جاهز في الكود لكن محتاج حساب تاجر Paymob فعلي ومفاتيحه (راجع `SETUP.md`).
