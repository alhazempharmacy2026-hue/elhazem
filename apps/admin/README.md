# لوحة تحكم صيدلية الحازم (Admin)

أداة داخلية للموظفين (صيادلة/مديرين) بس — مفيش تسجيل حساب ذاتي منها. بتُستخدم لمتابعة
طلبات العملاء الواردة من موقع/تطبيق الصيدلية، مراجعة الروشتات، تعيين مناديب التوصيل،
وإدارة كتالوج الأدوية والفئات. مبنية بـ React + Vite + TypeScript + Tailwind، وبتتكلم
مباشرة مع Supabase (بدون سيرفر backend مخصص) عن طريق حزمة `@elhazem/shared`.

## التشغيل محليًا

من جذر المونوريبو:

```bash
npm install          # مرة واحدة لكل الـ workspace
npm run dev:admin     # أو: cd apps/admin && npm run dev
```

قبل التشغيل لازم تظبط ملف `.env` (راجع `.env.example`):

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

القيمتين موجودين في لوحة تحكم مشروع Supabase بتاعك: `Settings → API`. لو الملف ناقص،
الأداة هتعرض شاشة إرشادات بدل ما تكراش.

## حسابات الموظفين

مفيش شاشة تسجيل حساب جديد داخل الأداة دي عمدًا — الحساب لازم يتعمل من `supabase/migrations`
(seed) أو من لوحة تحكم Supabase، وبعدين عمود `profiles.role` بتاعه لازم يتظبط يدويًا لـ
`pharmacist` أو `admin` (عن طريق حساب `admin` موجود، أو مباشرة في قاعدة البيانات). أي حساب
بدور تاني (`customer`/`courier`) هيتمنع من الدخول برسالة واضحة بدل ما يحصل توجيه لا نهائي.

## البناء

```bash
npm run build -w @elhazem/admin
```
