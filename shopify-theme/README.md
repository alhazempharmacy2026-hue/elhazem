# El Hazem Beauty — قالب شوبيفاي لمستحضرات التجميل

قالب **Online Store 2.0** مبني من الصفر، عربي RTL بالكامل، ومظبوط على السوق المصري:
الدفع عند الاستلام، الشحن للمحافظات، زر واتساب، وسرعة عالية (JavaScript خفيف بدون أي مكتبات خارجية).

> مبني وتم فحصه بـ `shopify theme check` — **صفر أخطاء وصفر تحذيرات**.

---

## المحتويات

| المجلد | إيه اللي جواه |
|---|---|
| `layout/` | `theme.liquid` (كل الصفحات) و `password.liquid` (صفحة "قريبًا") |
| `templates/` | قوالب الصفحات: الرئيسية، المنتج، المجموعة، العربة، البحث، المدونة، 404، وصفحات الحساب |
| `sections/` | الأقسام القابلة للسحب والإفلات من محرر شوبيفاي |
| `snippets/` | مكوّنات متكررة (كارت المنتج، السعر، الأيقونات، سطر العربة...) |
| `assets/` | `base.css` و `theme.js` |
| `config/` | إعدادات القالب (الألوان، الخطوط، واتساب، الشحن المجاني...) |
| `locales/` | `ar.default.json` (اللغة الأساسية) و `en.json` |

## التركيب على المتجر

محتاج [Shopify CLI](https://shopify.dev/docs/api/shopify-cli) متثبت.

```bash
cd shopify-theme

# معاينة حية على متجرك من غير ما ترفع حاجة
shopify theme dev --store اسم-متجرك.myshopify.com

# رفع القالب كنسخة غير منشورة (آمن — مش هيمس القالب الشغال)
shopify theme push --unpublished --theme "El Hazem Beauty"

# فحص القالب
shopify theme check
```

بدون CLI: اعمل ZIP لمحتويات مجلد `shopify-theme` (مش المجلد نفسه) وارفعه من
**Online Store → Themes → Add theme → Upload zip file**.

## أول ٧ خطوات بعد التركيب

1. **القوائم**: `Navigation` → اعمل قائمة `main-menu` (العناية بالبشرة / المكياج / الشعر / العطور) وقائمة `footer` (سياسة الاستبدال، الشحن، تواصلي معانا).
2. **إعدادات القالب**: `Customize → Theme settings`
   - **التواصل**: حط رقم الواتساب بالصيغة الدولية بدون `+` (مثال: `201012345678`).
   - **عربة التسوق**: حدد **حد الشحن المجاني** بالجنيه (افتراضيًا 1000).
   - **الألوان والخط**: الخط الافتراضي Cairo، وفيه Tajawal و Almarai و IBM Plex Sans Arabic.
3. **العملة واللغة**: `Settings → Store details` → العملة **EGP**، و`Settings → Languages` → العربية كلغة أساسية.
4. **المجموعات**: اعمل مجموعات للأقسام واربطها في قسم "أقسام المتجر" وقسمي "الأكثر مبيعًا" و"وصل حديثًا" في الصفحة الرئيسية.
5. **الشحن**: `Settings → Shipping` → اعمل مناطق (القاهرة والجيزة / الدلتا / الصعيد / الساحل) بأسعار مختلفة، وقاعدة **شحن مجاني فوق المبلغ** اللي حطيته في إعدادات القالب.
6. **الدفع عند الاستلام**: `Settings → Payments → Manual payments → Cash on Delivery (COD)`.
7. **الصفحات**: اعمل صفحة `تواصلي معانا` واختار لها قالب **contact** عشان يظهر فورم التواصل.

## الأقسام الجاهزة

**الصفحة الرئيسية** (كلها قابلة للترتيب والحذف من المحرر):

- **بانر رئيسي** — سلايدر بصور وعناوين وأزرار، تبديل تلقائي وسحب بالإصبع.
- **مميزات المتجر** — ٤ شارات ثقة (شحن، دفع عند الاستلام، أصلي ١٠٠٪، استبدال).
- **أقسام المتجر** — كروت أقسام (مربعة أو دائرية).
- **مجموعة منتجات** — تقدر تكرره أكتر من مرة (الأكثر مبيعًا، وصل حديثًا، عروض...).
- **بانر ترويجي** — صورة + نص + زر.
- **عرض بعدّاد تنازلي** — العدّاد بيختفي لوحده بعد انتهاء الوقت.
- **آراء العملاء** و **الأسئلة الشائعة** و **نص حر**.

**صفحة المنتج** — كل جزء بلوك تقدر ترتبه أو تشيله:
الماركة، الاسم، السعر (مع نسبة الخصم وقيمة التوفير)، حالة التوفر مع **تنبيه قرب النفاد**،
اختيار المواصفات (بيدعم **درجات الألوان كـ swatches** بصورة الدرجة نفسها)، أزرار الشراء + الدفع السريع،
شارات ثقة، **زر سؤال على واتساب** بيبعت اسم ورابط المنتج، الوصف، تفاصيل قابلة للطي (المكونات / طريقة الاستخدام / الشحن)، كود المنتج، ومشاركة.
تحت في الموبايل فيه **شريط إضافة ثابت** بيظهر مع النزول، و**منتجات مقترحة** بتتحمّل من Shopify Recommendations API.

**صفحة المجموعة** — فلاتر شوبيفاي الأصلية (نوع/ماركة/نطاق سعر)، ترتيب، ترقيم صفحات، وشبكة بأعمدة قابلة للتحكم.

**العربة** — درج جانبي بيتحدّث بـ AJAX، شريط تقدّم للشحن المجاني، وملاحظة الدفع عند الاستلام.

## ملاحظات تقنية

- **لا jQuery ولا أي مكتبة خارجية.** كل جزء تفاعلي مكتوب كـ Custom Element عشان الأقسام اللي بيعيد شوبيفاي رسمها (Section Rendering API) تشتغل من غير ما تفضل تربطها من تاني.
- الصور كلها `srcset` + `sizes` + `loading="lazy"` ما عدا أول صورة في الصفحة (`fetchpriority="high"`) — ده أهم عامل في سرعة الموبايل وسعر إعلانات فيسبوك.
- الاتجاه `rtl` بيتحدد من لغة الصفحة تلقائيًا، والـ CSS كله بيستخدم خصائص منطقية (`inset-inline`, `padding-inline`) فالقالب هيشتغل صح لو ضفت الإنجليزية كلغة تانية.
- بيانات منظمة (JSON-LD) للمنتج والمتجر + Open Graph — مهمة لجوجل وللينكات على فيسبوك وواتساب.
- الخطوط العربية من Google Fonts لأن مكتبة خطوط شوبيفاي مفيهاش خطوط عربية كويسة؛ محمّلة بـ `preconnect` و `display=swap` ومعاها خط احتياطي من النظام. (ده سبب تعطيل قاعدة `RemoteAsset` في `.theme-check.yml`.)

## أفكار للتطوير بعد الإطلاق

- تقييمات المنتجات (Judge.me أو Shopify Product Reviews) — أهم عامل ثقة في السوق المصري.
- تكامل شركة شحن (Bosta / Mylerz / Aramex) لتتبّع الشحنات تلقائيًا.
- مسح المنتج بـ WhatsApp Business API للطلبات اللي بتيجي من السوشيال.
- بكسل فيسبوك + Google Analytics 4 من `Settings → Customer events`.
